A side-by-side AsciiDoc editor and live preview. Rename the document in the
header, pick a preview theme, and watch the preview follow your cursor.

== Getting started

Type on the left. The preview on the right updates as you go and *scrolls to
the block you are editing* — the matching block flashes briefly.

TIP: Drag the splitter to resize, or collapse either pane with the ⟨⟩ button.
